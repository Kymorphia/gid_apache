# gid_apache - giD Apache Arrow and Parquet bindings

D language bindings for the [Apache Arrow](https://arrow.apache.org/) GLib libraries (Arrow, ArrowDataset, ArrowFlight)
and Parquet GLib, generated by [gidgen](https://github.com/Kymorphia/gidgen/), for use with [dub](https://dub.pm/).

This repository is a companion to the main [giD](https://github.com/Kymorphia/gid) package repository.
It keeps the many versions of these packages out of the main repository and uses the packages of **gid** (glib2, gio2, etc.)
as dependencies, instead of containing copies of them.

## Packages

Each Arrow release has a set of sub-packages, which is named after the major version of the C GLib library
(and its GIR namespace version): `arrow19` through `arrow23`, `arrowdataset19`..`arrowdataset23`,
`arrowflight19`..`arrowflight23`, and `parquet19`..`parquet23`.
The Parquet, ArrowDataset and ArrowFlight packages depend on the Arrow package of the same version.

Packages are namespaced with a `gid` prefix and the package name including its major version.
So to import the statistics module from parquet v23, do:
```D
import gid.parquet23.statistics;
```

Multiple versions of the libraries can be loaded and selected at runtime, depending on which ones are available using gid
`isLibAvailable`. See giD documentation for more details.


See the [packages README](packages/README.md) for the list of packages.

## Usage

Add `gid_apache` and `gid` as dependencies of your dub project and use the sub-package for your Arrow version, for example:

```json
"dependencies": {
  "gid_apache:arrow23": "*",
  "gid_apache:parquet23": "*"
}
```

The `gid` packages needed are pulled in automatically (`"gid:glib2": "~>0.9.17"`, etc.).
The matching Arrow GLib shared libraries (`libarrow-glib.so.2300` for version 23, etc.) are loaded at runtime.

The bindings are used like those of the other giD packages, consult the [giD README](https://github.com/Kymorphia/gid) for more information.

## Regenerating the bindings

You only need this to develop the bindings, users just depend on the dub packages as described above.

The generator needs the defs and GIR files of the main giD repository to resolve the types of the GLib and Gio bindings, as
well as its `gidgen` submodule. Check out **gid** as a sibling of this repository, at the version matching the dependency
in [gidgen.json](gidgen.json) (or `main` for development), then run **gidgen** from this repository:

```sh
git clone --recurse-submodules https://github.com/Kymorphia/gid.git
git clone https://github.com/Kymorphia/gid_apache.git
cd gid_apache
make binding   # runs gidgen, which reads gidgen.json (defs/, gir/, packages/ and the gid dependency in ../gid)
make packages  # builds all of the packages against ../gid (registered with dub add-local)
```

The `gid` dependency in `gidgen.json` makes gidgen load the defs and GIRs of **gid** only for resolving types,
its packages are not written here and the dependencies on them are generated as `"gid:glib2": "~>0.9.17"`.
The `version` there is the dub version constraint used in all generated package dependencies on gid,
`gidgen` needs to be a version which supports the `dependencies` option.

Adding a new Arrow version consists of adding the GIR files (`gir/Arrow-N.0.gir`, `ArrowDataset-N.0.gir`,
`ArrowFlight-N.0.gir`, and `Parquet-N.0.gir`, as installed by the Arrow GLib `-devel` packages) and a definition file for each
(copy for example `defs/arrow23.d` to `defs/arrowN.d` and change the version numbers), and running `make binding`.
